# Superstore Sales & Profit Dashboard

## 📌 Project Overview

An interactive **Power BI dashboard** designed to analyze Superstore sales, profit, orders, customer segments, regions, shipping modes, and product performance.

## 🎯 Objective

To transform Superstore data into an interactive dashboard and identify key sales and profitability trends for better business understanding.

## 📊 Dashboard Highlights

- Sales, profit, and order KPIs
- Sales and profit trends over time
- Category and sub-category performance
- Regional and segment analysis
- Shipping mode analysis
- Discount vs. profit analysis
- Interactive filters for **Date, Region, Segment, and Ship Mode**

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Excel

## 📁 Files

- `Superstore_Dashboard.pbix` — Power BI dashboard
- `dataset.csv` — Source dataset

## 💡 Key Insights

- Sales show an overall upward trend across the analyzed period.
- Technology is one of the strongest-performing categories.
- The Consumer segment contributes the largest share of sales.
- Standard Class is the most commonly used shipping mode.
- Higher discounts tend to be associated with lower profitability.

## 📈 Outcome

The dashboard transforms raw Superstore data into an interactive business intelligence report for exploring sales performance, profitability, and customer and product trends.
